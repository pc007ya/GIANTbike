# 管理員給初始帳密，再綁定 Google
- 管理員在 Firebase Authentication 為承辦人設定獨立初始密碼，將同一 UID、公司信箱和廠商登記在管理中心，並透過公司核准的私下管道交付。既有帳號由有 IAM 權限的管理員按 UID 設定密碼，不刪除重建，不更改供應商／專案分配。不將密碼存入 Git、Firestore、試算表、日誌或聊天。
- 承辦人收到帳密後直接登入、驗證公司信箱。忘記密碼只用於救援，不是開戶必要程序。登入後可更換密碼或從「我的帳號」綁定並確認 Google。Google 綁定不會新增供應商，也不會給其他廠商專案。
- 候選分支改為每廠商一份獨立投影，移除共用目錄讀取。不把部署中的舊靜態資料視為已受保護。部署前要抽離任何業務靜態檔案、做私有素材路徑及 Firebase 模擬器回歸，驗證 A/B/CIC 和同 UID Google。舊專案的公開 Git 歷史仍包含圖資、資料和預覽；不能直接重新公開此完整歷史。可用獨立乾淨發布來源放純登入與介面程式碼，不把受限資料放回公網。
- 在管理員確認現有完整主檔與七家分配、備份擬寫入的廠商投影後才執行投影發布；主檔、供應商 UID、現有業務文件不應因啟用而被覆蓋。此候選尚未部署。
